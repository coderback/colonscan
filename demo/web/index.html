ColonoScan

Finding polyps in colonoscopy images, pixel by pixel

ColonoScan is a university project: a platform for analysing colonoscopy video and histopathology slides with deep learning. This page shows the trained polyp segmentation model's real output on public images, and lets you run that model on them in your own browser.

Run the model live in your browser

Your device runs the model on the image above, using WebAssembly. The first run downloads about 41 MB. No image or result is sent to a server, and it only runs on these eight public images, so there is no upload.

Histopathology patch classifier

The second model, an EfficientNet-B3, labels colon tissue patches as normal or adenocarcinoma. It is not interactive here.

800 of 800

Test patches classified correctly in the saved run of monai-efficientnet-cnn.ipynb (390 normal, 410 adenocarcinoma), on the notebook's lung_colon_image_set data. A perfect score on one public patch dataset says little about real slides, and the model has not been tested on any other source.

How it works

  1. Prepare. Resize the frame to 256 by 256 and normalise it with ImageNet statistics.
  2. Segment. A UNet++ with an EfficientNet-b4 encoder outputs a probability for every pixel.
  3. Threshold. Pixels above 0.5 become the polyp mask, which is scaled back up over the frame.

The full system in the repo adds a Next.js frontend, a Django REST backend with Celery and PostgreSQL, and FastAPI inference services, run with Docker Compose. Only the model is shown here.

Saved results came from the PyTorch service in demo/api, in a local container limited to 2 CPU cores, where warm inference took about 1 to 4 seconds per image and used about 620 MB of memory. That service accepts no uploads and is not deployed.

Live runs use the same weights exported to ONNX, and onnxruntime-web 1.30.0 served from this site. The page repeats the same three steps in your browser, and no server does any inference. demo/export reproduces the model file and its comparison with PyTorch.

ColonoScan

Polyp segmentation and tissue classification with deep learning

ColonoScan is a university project: a platform for analysing colonoscopy video and histopathology slides with deep learning. This page shows both trained models' real output on public images, and lets you run them on those images in your own browser.

Test patches classified correctly (390 benign, 410 adenocarcinoma), in the saved run of monai-efficientnet-cnn.ipynb and again when demo/export rebuilt that split and re-ran the repo's weights. The 21.6 MB live model stores those weights as 16-bit floats, and it gave the same label as PyTorch on all 800.

Why this score flatters the model. LC25000's 10,000 colon images are rotated and flipped versions of just 500 originals, and the notebook splits them at random, so test patches can be near copies of training ones. Confidence near 100% on these patches is expected and does not mean the model would do this on real slides. It has not been tested on any other source.

How it works

  1. Prepare. Resize the frame to 256 by 256 and normalise it with ImageNet statistics.
  2. Segment. A UNet++ with an EfficientNet-b4 encoder outputs a probability for every pixel.
  3. Threshold. Pixels above 0.5 become the polyp mask, which is scaled back up over the frame.

The patch classifier resizes each patch to 224 by 224, normalises it the same way, and outputs a probability for each class.

The full system in the repo adds a Next.js frontend, a Django REST backend with Celery and PostgreSQL, and FastAPI inference services, run with Docker Compose. Its histopathology service also has a whole-slide route, which this page doesn't run. Only the two models are shown here.

Saved results came from the PyTorch service in demo/api, in a local container limited to 2 CPU cores, where warm inference took about 1 to 4 seconds per image and used about 620 MB of memory. That service accepts no uploads and is not deployed.

Live runs use the same weights exported to ONNX, and onnxruntime-web 1.30.0 served from this site. The page repeats the same steps in your browser, and no server does any inference. demo/export reproduces both model files and their comparisons with PyTorch.
